MSR 2026 Mining Challenge, Rio de Janeiro, Brazil

LGTM! Characteristics of Auto-Merged LLM-based Agentic PRs

Ruben Branco, Paulo Canelas, Catarina Gamboa, Alcides Fonseca (equal contribution)

MSR 2026 - 23rd International Conference on Mining Software Repositories, Mining Challenge.

Paper Artifact Poster Cite

Coding agents open pull requests faster than people can review them, so some repositories merge them without anyone commenting. We looked at ~33,000 agentic PRs from 2,800 repositories to see which ones get through.

Poster for MSR 2026

What counts as an auto-merge

A PR merged with no reviews and no comments from anyone but its author or bots. Switch events on and off.

    All or nothing

    Most repositories auto-merge every agentic PR or none. Agents get auto-merged more than humans in every task type. Select a task.

      Table view (Figure 1, all six bands)

      Small changes get through

      Auto-merged PRs are smaller, and maintainers are wary of agents deleting code. Each dot is one repository.

      Mature repositories review more

      Repositories that never auto-merge agentic PRs are bigger, healthier and run more checks (Table 1, medians, all p < 0.001).

      Not all agents are the same

      Per agent, against human PRs in the same repositories. The all-or-nothing pattern fades, and only OpenAI Codex differs significantly from humans. Select an agent.
