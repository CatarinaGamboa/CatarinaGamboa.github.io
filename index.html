What I work on

1. Understand

Why developers avoid liquid types

Liquid types catch more bugs, yet few developers use them. We watched 19 people learn and use LiquidHaskell and found nine barriers, from error messages to proof engineering.

PLDI 2025 project page
2. Build

LiquidJava

Liquid types for Java, designed with Java developers. In a study with 30 of them, every one found the bug with LiquidJava, and all 30 said they'd use it.

ICSE 2023 project page
3. Automate

Barista

Writing specifications is the hardest barrier, so LLM agents do it. 87% precision, 4.2× faster than an expert, about $2.20 per class.

ASE 2026 project page
